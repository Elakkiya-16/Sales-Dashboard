# Sales Dashboard – Power BI

## Project Overview
The **Sales Dashboard** is an interactive data visualization project developed using Microsoft Power BI. It provides insights into sales performance, profit, quantity, payment modes, customer contributions, and monthly trends.

The dashboard presents key business metrics through interactive charts and KPI cards, helping users understand sales performance and identify important patterns in the data.

## Objectives
- Analyze overall sales amount, profit, and quantity.
- Compare profit across different product sub-categories.
- Understand quantity distribution by payment mode.
- Analyze sales performance across product categories.
- Identify customers contributing to sales.
- Track monthly profit trends.
- Explore quarterly performance using slicers.

## Tools and Technologies
- Microsoft Power BI Desktop
- Power Query
- Data Visualization
- Data Analysis

## Dashboard Features

### 1. Key Performance Indicators (KPIs)
The dashboard displays three important metrics:
- Total Quantity
- Total Profit
- Total Amount

### 2. Quarterly Filter
A quarter slicer allows users to filter the report by:
- Qtr 1
- Qtr 2
- Qtr 3
- Qtr 4

### 3. Profit by Sub-Category
A bar chart compares profit across product sub-categories, helping identify the highest and lowest contributing sub-categories.

### 4. Quantity by Payment Mode
A donut chart visualizes the distribution of quantities across different payment modes.

### 5. Quantity and Amount by Category
A donut chart compares quantity and amount across product categories.

### 6. Amount by Customer
A column chart displays the sales amount contributed by individual customers.

### 7. Monthly Profit Analysis
A line chart illustrates monthly profit trends and highlights changes in profitability throughout the year.

## Data Fields Used
The report uses fields from the following tables:

**Orders**
- Order Date
- Customer Name

**Details**
- Category
- Sub-Category
- Quantity
- Profit
- Amount
- Payment Mode

## Project File
- `Sales_Dashboard.pbix` – Power BI report file containing the dashboard and visualizations.

## How to Open the Project
1. Install Microsoft Power BI Desktop.
2. Download or clone this repository.
3. Open `Sales_Dashboard.pbix` using Power BI Desktop.
4. Explore the dashboard using the available quarterly slicer and visual interactions.

## Conclusion
This Sales Dashboard provides an interactive overview of business performance through KPI cards and multiple visualizations. It helps users analyze profit, quantity, sales amount, customer contributions, payment preferences, and monthly trends in a single report.
